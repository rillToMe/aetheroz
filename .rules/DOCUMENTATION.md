# KyuzenOS Documentation Rules

Part of the KyuzenOS Development Rules. See `RULES.md` for general principles.

---

# 1. Documentation Requirements

Documentation is mandatory.

Every feature update must also update:

- README.md
- Relevant documentation inside /docs
- Driver documentation
- Architecture documentation

If behavior changes, documentation must change.

Documentation and implementation must always stay synchronized.

---

# 2. Documentation Update Checklist

Whenever a feature changes, verify:

[ ] README updated

[ ] docs updated

[ ] architecture updated

[ ] API documentation updated

[ ] examples updated
